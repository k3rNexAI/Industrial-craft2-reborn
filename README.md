# Industrial Reborn — Minecraft 26.3 / Fabric

Самостоятельная реализация промышленного техномода, вдохновлённая системами IC2 Experimental. Название, код и ресурсы проекта оригинальные; проект не является официальным IC2 и не включает его исходники или ассеты.

## Требования

- Minecraft Java Edition 26.3
- Java 25 JDK
- Gradle 9.6+
- Fabric Loader 0.19.5+
- Fabric API 0.163.0+26.3

## Сборка

Откройте папку проекта в IntelliJ IDEA (Gradle project) или выполните команды из корня:

```bash
gradle build
```

Если Gradle не установлен, сначала создайте wrapper совместимой версией Gradle 9.6:

```bash
gradle wrapper --gradle-version 9.6.0
./gradlew build
```

Windows: `gradlew.bat build`.

Готовый JAR появится в `build/libs/`. При первом запуске Gradle скачает Minecraft, mappings и зависимости, поэтому требуется доступ к сети.

## Что уже заложено

- Fabric entrypoint и регистрация контента.
- Базовые материалы: медная проволока, резина, очищенная медь и энергетический кристалл.
- Блоки-макеты: генератор, накопитель EU и дробитель.
- Независимая модель EU-энергии с ограничением ёмкости, приёмом/отдачей и передачей энергии с потерями.
- Документация архитектуры и план следующих этапов.

**Важно:** это исходная стартовая база, а не законченный клон IC2. Блоки-макеты пока не содержат полноценной машинной логики, GUI, рецептов и сохранения инвентаря. Эти системы следует реализовывать последующими этапами и проверять сборкой на конкретном окружении 26.3.

## Архитектура

- `content/ModItems.java` — предметы.
- `content/ModBlocks.java` — блоки.
- `energy/EnergyStorage.java` — хранилище EU.
- `energy/EnergyTransfer.java` — расчёт передачи и потерь.
- `machine/` — место для BlockEntity, инвентарей, рецептов и GUI.
- `data/` — локализация, модели, рецепты и теги.

## План разработки

1. **Ядро** — конфигурация, регистрация контента, EU storage, сетевые тесты.
2. **Машины** — BlockEntity, слоты, прогресс обработки, сериализация состояния.
3. **Рецепты** — дробитель, электрическая печь, экстрактор, компрессор, переработчик.
4. **Сеть EU** — кабели по классам напряжения, соединения, потери, перегрузки и защита.
5. **Генерация** — обычный генератор, солнечная/геотермальная энергия, водяная мельница.
6. **Прогрессия** — руды, резина, сплавы, инструменты, батареи и броня.
7. **Реактор** — топливо, тепло, охлаждение, повреждения и аварийные состояния.
8. **Полировка** — GUI, звуки, частицы, датапаки, баланс, локализация и тесты.
